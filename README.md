## ⚙️ Getting Started

### Prerequisites

- Node.js
- npm
- MongoDB

### Installation

```bash
git clone https://github.com/Pragati-coders/ChatApp.git

cd ChatApp

npm install
```

Run the project:

```bash
npm run dev
```

## 🔑 Environment Variables

Create a `.env` file.

```env
PORT=

MONGODB_URI=

JWT_SECRET=

CLIENT_URL=
```

Update these values based on your local or production setup.
